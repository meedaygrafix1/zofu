# Pro Feature: AI Cover Letter Generation

## Overview

The AI Cover Letter feature is already implemented end-to-end in the codebase (generated by the `/api/amplify` endpoint alongside resume optimization, stored in sessions, rendered in `ResumePreview`). However, it is currently **available to all free users** while the billing page lists it as a **Pro-only feature**.

This document tracks the plan to:
1. Fix the **empty state** on the Cover Letter tab in `ResumePreview`
2. Add a **Pro upsell gate** on the Cover Letter tab for free-tier users (when billing goes live)

---

## Current State

- **`src/lib/prompts.ts`** — `AMPLIFY_PROMPT` includes `"coverLetter"` in its required JSON output. The AI always generates a cover letter.
- **`src/context/OptimizerContext.tsx`** — `coverLetter` state is set from API response and persisted in sessions.
- **`src/components/ResumePreview.tsx`** — A "Cover Letter" tab (`viewMode === "coverLetter"`) exists but renders **nothing** when `coverLetter` is empty (no empty state UI).
- **`src/app/app/billing/page.tsx`** — "AI Cover Letter generation" is listed as a Pro-only feature (`₦2,000/month`), but there is no enforcement in code.

---

## Bugs / UX Issues to Fix

### 1. Missing Empty State on Cover Letter Tab

**File:** `src/components/ResumePreview.tsx` — line 626

**Problem:** When a user clicks the "Cover Letter" tab before amplifying (or if cover letter data is missing), the content area is blank. No guidance is provided.

**Fix:** Add an empty state UI that:
- Shows a friendly illustration/icon
- Explains the cover letter is generated automatically after clicking "Optimize"
- Matches the existing empty state style (see `File01Icon` usage at line 472)

```tsx
{viewMode === "coverLetter" && !coverLetter && (
  <motion.div
    key="coverLetter-empty"
    initial={{ opacity: 0 }}
    animate={{ opacity: 1 }}
    exit={{ opacity: 0 }}
    className="flex flex-col items-center justify-center py-16 text-center"
  >
    <div className="flex h-16 w-16 items-center justify-center rounded-2xl bg-primary-ultra-light mb-4">
      <File02Icon className="h-8 w-8 text-primary" />
    </div>
    <h3 className="text-lg font-semibold text-foreground mb-2">Cover Letter</h3>
    <p className="text-sm text-muted max-w-xs">
      Your personalized cover letter will appear here after you click "Optimize".
      It's crafted automatically from your resume and the job description.
    </p>
  </motion.div>
)}
```

### 2. Pro Gate (Future — when billing goes live)

**Files:** `src/components/ResumePreview.tsx`, `src/context/OptimizerContext.tsx`

**Plan:**
- Pass a `isPro: boolean` prop into `ResumePreview` (sourced from Supabase user metadata / subscription status)
- When `!isPro && viewMode === "coverLetter"`:
  - Show a locked/blurred cover letter preview with a "Upgrade to Pro" overlay
  - Link to `/app/billing`
  - Do NOT call the cover letter generation endpoint (or strip it from the prompt for free users) — saves costs

**Gate UI sketch:**
```
┌─────────────────────────────────────┐
│  [blurred cover letter text]        │
│         🔒 Pro Feature              │
│  Unlock unlimited cover letters     │
│  [Upgrade to Pro →]                 │
└─────────────────────────────────────┘
```
